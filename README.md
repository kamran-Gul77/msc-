# LinguaAI

LinguaAI is an AI-powered language learning platform designed to help users improve their english.

The goal of LinguaAI is to make language learning more interactive, practical, and accessible by combining modern AI technologies with a clean and intuitive user interface.

---

## Features

- **AI Conversations** – Practice real-world conversations with an AI assistant.
- **Interactive Lessons** – Learn vocabulary and grammar in practical contexts.
- **Progress Tracking** – Monitor learning performance and improvements.

---

## 🛠 Tech Stack

**Frontend**

- React / Next.js
- TypeScript
- Tailwind CSS
- ShadCN UI

**Backend / Services**

- Supabase (Authentication & Database)
- AI APIs (for conversation and language processing)

**Other Tools**

- Git & GitHub (version control)

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/lingua-ai.git
````

Navigate to the project:

```bash
cd lingua-ai
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:3000
```
